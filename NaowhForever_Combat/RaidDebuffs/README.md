# Raid Debuffs

A bar of the raid debuffs you pick (Sunder Armor, Faerie Fire, the warlock curses, Demoralizing
Shout, ...), one icon each, on your target. A debuff that is up shows bright, with its stacks and
time left; a missing one shows dimmed. Highlight Missing turns that round: missing debuffs light up
with a red edge and the ones already up fade. Its settings page is Raid Debuffs/Settings. Off by
default (`enabled` in the `raidDebuffs` store, from `ns.FEATURES.raidDebuffs`).

## Layout

```
NaowhForever_Combat/RaidDebuffs/
  RaidDebuffs.xml          every file, in load order, included by Combat.xml
  Data/
    Spells.lua             each debuff's spells by ID (ns.RaidDebuffSpells), generated by
                           Tools/build/raid_debuffs.py
  RaidDebuffs.lua          the settings (ns.RaidDebuffSettings) and the module table (ns.RaidDebuffs, RD)
  View/
    Style.lua              its look (RD.Style), on top of Shared/Style.lua
  UI/
    Bar.lua                the bar: its AuraContainer slots, the missing icons under them, events and
                           Unlock Mode
    SettingsPage.lua       the Raid Debuffs/Settings page, declared as cards
  README.md                this file
```

Each debuff has its own switch, `debuff_<key>`. Sunder Armor, Faerie Fire, the three curses,
Demoralizing Shout and Thunder Clap start on.

## Why

- Forever refuses addons aura data in combat, so the addon never knows whether a debuff is up.
  Blizzard's AuraContainer does: each debuff gets an aura slot (`AddAuraSlot`), which the game
  shows while one of its spells is on the target and hides while none is. Under each slot sits
  an icon of our own, the missing look, which shows through whenever the slot is empty.
- That is why Highlight Missing fades the debuffs that are up rather than hiding them: hiding
  them would take knowing they are up. The slot's own icon is drawn dim over an opaque ground,
  so it still covers the lit missing icon under it.
- The AuraContainer matches an enemy's debuffs by spell ID only, so the spell data lists every
  rank and the NPC and item versions, built from the game's tables. Forever renumbered some
  spells (Curse of the Elements and Curse of Shadow have none of their classic IDs).
- The container has no way to take a slot away, so every debuff gets its slot when the bar is
  built and a debuff switched off has its slot disabled.
- A slot's frame denies addon code while auras are secret, so the bar is built, laid out and
  restyled only out of combat with auras readable; a change made meanwhile waits for
  `PLAYER_REGEN_ENABLED` or `ADDON_RESTRICTION_STATE_CHANGED`, since auras can stay secret out of
  combat (an encounter, a battleground).
- Without an enemy target (or outside a raid or group, by Show) the bar fades out by alpha, which
  is safe in combat. Where the game will not say whether the target is hostile (a secret value),
  it stays. A target turning hostile or friendly (`UNIT_FACTION`, `UNIT_FLAGS`) fades it too.
- The slot buttons take no mouse, so a faded bar never catches a click or shows a tooltip.
