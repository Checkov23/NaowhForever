# Journeys Data

The walking maps Journeys (`NaowhForever_Utilities/Journeys`) plans walks on, generated by `Tools/nav` (its README has how
and why), and the quest spots for a tracked quest the game marks nowhere. Load-on-demand: Journeys
loads it on the first journey, out of combat, so a player who never plans one never loads it.

## Layout

```
NaowhForever_JourneysData/
  NaowhForever_JourneysData.toc   its metadata (LoadOnDemand), and JourneysData.xml
  JourneysData.xml                every file, generated by Tools/nav/pack.mjs
  Data.lua                        the tables the map files fill: ns.JourneyData
  QuestSpots.lua                  each quest's turn-in and objective camps (ns.JourneyQuestSpots),
                                  generated by Tools/build/journeys_quests.py
  Data/Map<map>.lua               a map's crossings and the walks between the network's places
  Data/Map<map>_<n>.lua           a map's tiles, in parts under 3.5 MB
```

## Why

- Every tile, the crossings and the walks are CBOR, deflated, in Base64: the client decodes all three
  natively (`C_EncodingUtil`), and the addon's files must stay ASCII.
- The tile files are split under 3.5 MB each: the checks refuse files over 5 MB.
- Quest spots contain a turn-in or false, objective camps, and optionally outdoor dungeon entrances
  in slot 3. Entrances are incomplete-quest guidance only, separate from exact objective locations.
- Optional slot 4 contains alternative turn-ins as `{ uiMapID, x, y, side }`, where side is `A`,
  `H` or `AH`. Slot 3 remains present when empty so the slot meanings never shift.
